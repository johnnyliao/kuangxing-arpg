# 遊戲日文語音整合

已整合到 index.html。直接開啟專案根目錄的 START-GAME.cmd 或 index.html 即可試玩，不需啟動伺服器、安裝 Python 或連線下載模型。

## 動作對應

| 遊戲事件 | 錄音 |
|---|---|
| 開始章節 | intro「俺は悪魔だ」／taunt「俺が化け物？」交替 |
| 輕攻擊 | light-1、light-2，避免連續選同一片段 |
| 重攻擊 | heavy |
| 氣功彈 | blast |
| 閃避 | dash |
| 集氣 | charge「カカロット！」，開始按住時喊一次；持續集氣不重播，鬆開後仍讓這一聲播放完 |
| 受傷 | hurt |
| 首次暴走 | rage |
| 大絕發動 | victory、victory-alt 大笑聲，隨機播放 |
| 倒地 | death |
| 過關／結局開始 | victory、victory-alt 笑聲 |
| 偶發戰鬥語音 | 笑聲、「我是惡魔」、「你說我是怪物？」隨機選擇 |

共 14 個片段，11 組遊戲事件。事件冷卻、語音優先級與檔案對應在 index.html 的 VOICE_EVENTS；來源與精確裁切時間記錄於 game-manifest.json。voice-pack.js 是由製作腳本產生的本機載入清單。

## 聲音處理與播放

- 使用使用者提供影片的錄音，沒有聲音複製或合成模仿。集氣素材改用使用者另指定的 YouTube 影片。
- 在自動分析的候選區段內，以人聲頻帶能量挑選短音；高低通濾波、輕度降噪、響度調整與邊緣淡入淡出。
- 這些處理不是人聲分離。部分片段仍含配樂／戰鬥音效，短喊與受傷片段的角色身分未經人工確認；暴走與大絕來自低分數探索候選，作為試玩版暫用音。
- 集氣依使用者指定，只保留已確認五秒短版 kakarot-reference-1m30-1m35.mp3 的後面一句。裁取第 1.88–4.08 秒（原影片 1:31.88–1:34.08），輸出 charge-kakarot-last-line-v1.mp3，保留起音與尾音，不做降噪或響度處理。原始五秒參考檔保留。自動辨識仍會誤轉寫名字，僅協助定位；正確喊法依使用者確認。新檔名避免讀取舊版快取。
- 單一角色語音聲道；倒地、爆氣、受傷優先於普通攻擊。冷卻避免每拳重播長喊聲。
- 偶發語音於開場 14–24 秒後開始尋找空檔，成功播放後間隔 16–28 秒；只在待機／行走且敵人尚在、附近沒有貼身敵人時觸發。避開字幕、既有語音、受傷無敵、集氣、大絕、劇情和過關，與上一段語音至少間隔 2.5 秒。普通戰鬥語音可立即打斷偶發台詞。
- 主角保留故事字幕，取消原中文 TTS；戰鬥事件播放日文錄音。敵人仍使用原瀏覽器 TTS，強制劇情語音與錄音互斥。
- 「聲音」按鈕控制錄音、音效與 TTS；語音滑桿獨立控制錄音，音量保存在本機。切換頁面或離開視窗時停止角色語音。
- 集氣開始時可打斷其他錄音，避免喊聲被開場或偶發台詞擋住。音量滑桿有焦點時仍能使用 I 等字母操作；方向鍵則保留滑桿的原生操作。「試聽集氣怒吼」直接播放實際集氣片段。
- 素材缺失或播放遭瀏覽器阻擋時顯示提示，原合成音效與遊戲繼續運作。

## 驗證

在專案根目錄執行 `node audio/run-voice-check.cjs`。Chromium headless 驗證 14 檔解碼與實際播放啟動、冷卻、優先級、靜音、音量、事件觸發、場景切換及 25 秒遊戲邏輯模擬。截圖為 gameplay-with-voices.png。

測試的 autoplay-policy 只套用於 headless 測試程序。一般遊玩由 Enter／點擊開始；若仍無聲，按「試聽語音」啟用。

本機測試不等於真人聽辨與手感驗收，尤其短喊的說話者和混音品質仍需實際試玩檢查。

## 重新製作

使用 audio/.venv/Scripts/python.exe 執行 `audio/build-game-voices.py`，需要 FFmpeg 與 NumPy。腳本只讀取 source 音軌，覆寫 game 內的衍生片段、game-manifest.json 與 voice-pack.js，不修改原音軌。
